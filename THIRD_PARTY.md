# Third-party software

Packaged builds include an unmodified copy of **Spirula Studio** (GPLv3),
https://github.com/harry7557558/spirula-studio, at the release named in `SPIRULA_VERSION`.
Its complete source for that release is available at
`https://github.com/harry7557558/spirula-studio/releases/tag/<that version>`.
Spirula downloads AI masking models only when asked, under their own licences.

Insta Splat itself is GPLv3 (see `LICENSE`) and is built with Python and PyInstaller.
